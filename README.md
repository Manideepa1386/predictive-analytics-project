# Predictive Analytics Using Historical Data

## Project Description
This project predicts student performance using historical data and machine learning techniques. The dataset was preprocessed and analyzed using Python libraries such as Pandas, Matplotlib, and Scikit-learn.

A Linear Regression model was used to predict student marks based on study hours and attendance. The project also includes data visualization and performance evaluation.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Data preprocessing
- Data visualization
- Linear regression model
- Student performance prediction

## Files Included
- studentsperformance.py
- StudentsPerformance.csv

## Output
- Predicted values
- Accuracy evaluation
- Graph visualization
